Why brute force isn't good enough

It always finds the answer, but it pays for every pair. Add one more number and it has to be paired with everything already there, so the work grows with n², not n.

Two Sum, in one pass

Brute force keeps rescanning the array to find a partner. This version walks the array once and keeps a memory, a hash map called seen. For each number it asks one question: have I already passed the number that would complete the pair?

What changed from brute force

Both versions answer the same question, "where is my partner?" Brute force answers it by searching. This version answers it by remembering.

Two details make it work. The lookup happens before the insert, so a number can never pair with itself. And because the map only holds numbers to the left of i, the first time a partner exists, it is found immediately.
